# Casa Bilingvă 🏰🇷🇴

Lanzador Android de **Casa Bilingvă**, la app para aprender rumano en familia.

Al tocar el icono se abre la app en Chrome, con tu sesión de Claude:

- **CasaBilingva-JoseAntonio.apk**: entra como alumno.
- **CasaBilingva-Ruxandra.apk**: entra como jueza.

## Instalar
1. Abre la pestaña **Releases** de este repositorio desde el móvil.
2. Descarga la APK con tu nombre y ábrela (Android pedirá permitir instalar desde el navegador).
3. La primera vez, inicia sesión en claude.ai en Chrome.

Cada push a `main` compila las dos APK con GitHub Actions y publica una nueva versión.
